Internal launch checklist

What RankForge needs before public launch.

This page is a practical checklist for preparing the MVP for early paid users.

1. Stability

Remove old demo user fallbacks, confirm real Supabase user isolation, and verify lead detail opens the selected lead.

2. Billing

Create Stripe products, add Payment Links, and use a trusted webhook before marking any plan active.

3. Users tab

Track plan, billing status, Stripe customer ID, subscription ID, limits, and updated timestamps.

4. n8n limits

Enforce Free, Starter, and Growth limits in the workflow, not only in the frontend.

5. Credentials

Move private keys out of frontend and avoid hardcoded API keys in public files.

6. End-to-end test

Test signup, login, search creation, sync, leads, lead detail, feedback, export, admin quality, and logout.
